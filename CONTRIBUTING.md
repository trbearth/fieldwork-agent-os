# Contributing

Small, inspectable contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep new collectors permissioned, bounded, and fixture-testable.
3. Run `npm run doctor`, `npm run agents:fixture`, `npm test`, and `npm run build`.
4. Explain the user problem, source method, and safety implications in the pull request.

Do not include secrets, copied article bodies, private data, or sources that require scraping a logged-in page.
